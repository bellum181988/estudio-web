Política de privacidad de Estudio

Última actualización: 26 de noviembre de 2026. Estudio es una aplicación personal para llevar una biblioteca propia (qué es).

Qué acceso pide a Google

Solo el permiso https://www.googleapis.com/auth/drive.appdata: ver, crear y borrar los datos que la propia aplicación guarda en su carpeta oculta de tu Google Drive. No puede ver el resto de tus archivos, tu correo ni tus contactos.

Para qué se usa

Únicamente para sincronizar tu biblioteca entre tus propios dispositivos. Allí se guardan las fichas, las portadas y los cambios que haces, cifrados en tu dispositivo con una clave que solo tienes tú.

Qué recibe el autor de la aplicación

Nada. No hay servidor propio, cuentas de Estudio, publicidad ni herramientas de analítica. La aplicación habla directamente con Google desde tu dispositivo. Los datos de Google no se venden, no se comparten con terceros, no se usan para publicidad ni para entrenar modelos, y nadie los lee. El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de uso limitado.

Qué se guarda en tus dispositivos

  • Teléfono (web): tu biblioteca, las portadas, la clave de cifrado y un permiso temporal de Google, en el almacenamiento del navegador.
  • Ordenador: tu biblioteca y, protegidos por el sistema, el permiso renovable de Google y la clave. La aplicación puede guardar además tu código de recuperación en un archivo de su carpeta de datos.

Otros servicios

La versión web está alojada en GitHub Pages, y GitHub puede registrar datos técnicos de las visitas, como la dirección IP (privacidad de GitHub). El inicio de sesión y Drive son servicios de Google (privacidad de Google). Si abres un enlace de una ficha, se aplica la política de esa web.

Cómo borrar tus datos o retirar el acceso

  • En el teléfono: panel de sincronización, «Borrar los datos de este iPhone».
  • En Google Drive: Configuración, Administrar aplicaciones, Estudio: eliminar los datos ocultos de la aplicación o desconectarla.
  • En tu cuenta de Google: conexiones con apps de terceros.
